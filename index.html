01

Você pergunta. Ela responde. Você aceita.

A resposta chega rápido. É bem escrita, organizada em tópicos e assertiva como quem sabe do que está falando. Então vem o Ctrl+C + Ctrl+V.

A questão não é a IA estar certa ou errada. O problema é que um texto bonito parece verdadeiro — nosso cérebro confunde fluência com competência. E isso não é um detalhe de quem usa IA só para o trabalho da faculdade: é assim que muita gente hoje decide o que comprar, qual remédio tomar e até em quem votar.

Parar de usar IA não é a resposta. Continuar presente na conversa é.

Ao fornecerem respostas prontas, essas ferramentas reforçam modelos passivos de recepção do conhecimento. Resumo do artigo · Gaspar & Fina, 2026
02

O que a ferramenta faz

Turno a turno

Expõe pressupostos

Cada mensagem carrega axiomas implícitos. A ferramenta os detecta e devolve para você aceitar, rejeitar ou reformular — a escolha não é dela.

Confiança calibrada

Devolve perguntas

Quando o domínio permite, ela responde. Quando a pergunta esconde um juízo de valor, ela pergunta de volta antes de opinar por você.

Artefato de aprendizagem

Desenha o raciocínio

Posições, pressupostos e verificações viram vértices de um grafo persistente por sessão. Contradições e clusters temáticos deixam de ser momentos e viram objetos de reflexão.

03

7 perguntas para fazer antes de acreditar numa resposta de IA

Funcionam sozinhas, em qualquer ferramenta de IA. Não é preciso instalar nada — só é difícil manter a disciplina quando ninguém cobra.

01O que essa resposta está assumindo que eu nem percebi?+
Muitas respostas partem de pressupostos não assumidos. Torná-los explícitos é o primeiro movimento crítico. “Quais pressupostos você usou para chegar nisso?”
02Como eu saberia se isso estivesse errado?+
Informação factual precisa ser falseável — precisa poder ser verdadeira ou falsa. O que não pode ser refutado também não pode ser verificado. “Que evidência tornaria essa resposta falsa?”
03De onde vem isso?+
Uma resposta que não sabe de onde veio não deveria decidir nada importante por você. “Em que você se baseou? Isso é consenso ou é disputado?”
04Existe uma versão contrária?+
Peça o outro lado — e peça a melhor versão dele, não um espantalho fácil de derrubar. “Me dê o argumento mais forte contra o que você acabou de dizer.”
05O que ficou de fora?+
Toda resposta é um recorte de algo maior. Às vezes a informação que falta é exatamente a que mudaria sua decisão. “O que você deixou de fora e por quê?”
06Isso é fato, interpretação ou opinião?+
Modelos costumam evitar opinar, mas em casos de alucinação inventam sem avisar. Saber separar as três coisas é o que te protege. “O que aqui é dado verificável e o que é leitura sua?”
07Devo concordar porque é verdade ou porque é confortável?+
A pergunta mais difícil — e essa é para você, não para a IA. Se a resposta bate exatamente com o que você já achava, é hora de desconfiar mais, não menos. Pergunte a si mesmo, antes do Ctrl+C.
04

A pergunta que você faz decide a resposta que você recebe

✕ Em vez de

“Me explique a Revolução Francesa.”

✓ Peça

“Me faça perguntas que testem meu conhecimento sobre a Revolução Francesa e depois comente minhas respostas.”

A primeira te entrega um resumo. A segunda te testa.
✕ Em vez de

“Meu texto está bom?”

✓ Peça

“Quais os argumentos mais fortes contra o que eu escrevi?”

Pedir aprovação inclina a IA a elogiar. Pedir oposição gera informação construtiva.
✕ Em vez de

“Qual é melhor, A ou B?”

✓ Peça

“Quais pressupostos alguém precisa aceitar para preferir A? E para B?”

A escolha volta para você.
05

Como usar

ontology-app · para quem só quer conversar

Aplicação web

Backend em FastAPI, frontend em React (TypeScript). Roda a conversa e renderiza os registros epistêmicos da sessão.

# setup (primeira vez)
python -m venv .venv
.venv/Scripts/activate   # macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"
cd web && npm install

# rodar — dois terminais
uvicorn api.main:app --reload
npm run dev   # → localhost:5173

ontology-internal · para quem já usa Claude Code

Servidor MCP

Arquitetura host-cérebro: o LLM com quem você já conversa faz a percepção e a geração; o servidor guarda o estado epistêmico e decide o movimento socrático por regras auditáveis, sem chamar nenhum LLM — logo, sem chaves de API.

# setup
python -m venv .venv && .venv/Scripts/activate
pip install -e ".[dev]"

# registrar no Claude Code
claude mcp add ontology-internal -- \
  <repo>/.venv/Scripts/python.exe -m ontology_internal.server

# depois, no chat:
/mcp__ontology-internal__examinar
